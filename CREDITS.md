# Credits

nitincolors started from Pratiman Patel's
[`colormaps`](https://github.com/pratiman-91/colormaps) package (MIT), which
compiled the colour tables below. The tables remain under the terms of their
original authors. Please cite or credit the original source when a figure
using one of these maps is published.

| Collection | Original source |
|---|---|
| `carbonplan` | CarbonPlan colormaps — https://github.com/carbonplan/colormaps |
| `cartocolors` | CARTOColors (CARTO) — https://github.com/CartoDB/cartocolor |
| `cmasher` | CMasher (E. van der Velden) — https://github.com/1313e/CMasher |
| `cmocean` | cmocean (K. Thyng et al.) — https://matplotlib.org/cmocean/ |
| `colorbrewer` | ColorBrewer (C. Brewer, Penn State) — https://colorbrewer2.org |
| `colorcet` | Colorcet / CET perceptually uniform maps (P. Kovesi) — https://colorcet.holoviz.org |
| `cubehelix` | Cubehelix (D. Green) — https://people.phy.cam.ac.uk/dag9/CUBEHELIX/ |
| `ncar_ncl` | NCAR Command Language colour tables (UCAR) — https://www.ncl.ucar.edu/Document/Graphics/color_table_gallery.shtml (see `data/ncar_ncl/Copyright`) |
| `scientific` | Scientific colour maps (F. Crameri) — https://www.fabiocrameri.ch/colourmaps/ |
| `sciviz` | SciVisColor — https://sciviscolor.org |
| `tableau` | Tableau colour palettes — https://www.tableau.com |

The 93 NCL tables `MPL_*`, `cmocean_*` and `CBR_*` were removed from the
upstream package on 14 Sep 2021 (commit `f841fef`) while the documentation still listed some of
them; nitincolors restores them from the upstream git history so that every
name on the original website works.
